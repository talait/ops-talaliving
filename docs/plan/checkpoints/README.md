# Checkpoints

One file per checkpoint day, named for its date. A checkpoint is not a
feature day: it is walking the deployed demo end to end, with the people who
will actually use it, and writing down what happened.

- `2026-09-16.md` — D7, Flow B: request → IT gate → goods approval → round →
  transfer → receiving
- `2026-09-23.md` — D14, the full walkthrough and the Phase 2 handover

Each file answers four questions: what worked, what confused someone, what
the screen could not answer, and what we now know about the rules that we did
not know at the start.
